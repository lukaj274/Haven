# Boa Boing
Boa Boing is a game based on the famous snake game. However, we added a plot twist. The snake bounces off the walls to make the game more fun. The point of the game is to collect as many apples and mice as possible while avoiding the peppers. If the snake runs into its tail, or eats the pepper, then the game is over.

## Movement + Controls
The player can turn in either direction by using the arrow keys, 'A' and 'D' keys, or the triggers of a game controller.
